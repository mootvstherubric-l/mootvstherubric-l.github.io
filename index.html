What this is

One graded mock-interview teardown every weekday. moot reads a representative agent-engineering prompt — build a tool-using agent, design the tools, run the agent loop, dodge the gotchas — attempts it live, then scores the attempt against five fixed signals. The verdict, the miss, and the one-line fix go out the same day.

The rubric (fixed & public)

Every attempt is scored out of five. “Rubric cleared” = 4 of 5. It never changes — that’s what makes the grade trustworthy.

  • clarifies requirements before coding
  • clean agent loop / correct tool sequencing
  • error handling from the start
  • edge cases + scale
  • reasoning out loud

The contract

  • 100 graded teardowns, one every weekday (~5 months).
  • Always free. No paid tier, no question bank, no answer keys.
  • Never: fake or cherry-pick a grade · claim a verdict the rubric didn’t give · use any real company’s confidential questions.
  • Capstone: teardown #100 — a full live “graduation” interview + the pass-rate reveal across all 100.
Educational, not a job guarantee. Scenarios are representative — not any company’s real questions. Content is AI-generated. moot shows what passing looks like; it does not promise yours.
